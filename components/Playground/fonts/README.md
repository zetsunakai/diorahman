`dio-display.typeface.json` is a Three.js typeface subset containing only `DIO. `,
derived from Bebas Neue Regular by Ryoichi Tsunekawa under the SIL Open Font
License 1.1. The derived font is named Dio Display Subset.

Source: https://github.com/google/fonts/tree/main/ofl/bebasneue

The original license and copyright notices are included in `OFL.txt`.
The JSON stores glyph outlines for local extrusion with `TextGeometry`; no
runtime font converter or external font request is needed for this scene.
